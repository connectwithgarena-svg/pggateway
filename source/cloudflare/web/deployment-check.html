Fix a 404 or incomplete upload

  1. Extract the final FF Shop ZIP. Upload only the inner pages-upload.zip to your existing Cloudflare Pages project's Production deployment.
  2. The upload root must contain index.html, app.js, style.css, _worker.js, _routes.json and the other bundled files. Do not upload the outer ZIP, source ZIP, or a parent folder.
  3. Keep the D1 binding named DB, set PUBLIC_ORIGIN to this exact HTTPS origin without a trailing slash, and keep your private ADMIN_KEY_HASH secret.
  4. Back up your existing D1. Follow the included upgrade guide for your current schema. Never run the fresh database file over existing production data.
  5. Deploy again after saving bindings, then rerun this checker. Update the separate maintenance Worker and keep its five-minute cron.

Hindi: outer ZIP upload mat karo. Uske andar wala pages-upload.zip upload karo. Existing database aur admin key ko reset mat karo.

For a Git-integrated Pages project use its configured build or Wrangler deployment instead of dashboard drag-and-drop.
